Durable Workflow 2.0 機能索引

これは安定版 Durable Workflow 2.0 リリース系列の機能索引です。

サポートするインストール可能なチャネル​

成果物の正確な識別情報は、この機能概要ではなく、パッケージレジストリとリリースメタデータが管理します。

インターフェースサポートするチャネルこの索引での役割
CLI2.0 安定版機械可読な運用・診断クライアント。
PHP SDK2.0 安定版Cloud 名前空間ランタイムまたはセルフホスト Server 向けの、ファーストパーティのサービスモード durable-workflow/sdk クライアントとリモートのワークフロー・アクティビティ Worker。
組み込み Laravel エンジン2.0 安定版独自の記述ランタイム、永続化エンジン、キュー、リプレイを持つ、アプリケーション内の独立した durable-workflow/workflow デプロイモード。
Python SDK2.0 安定版Cloud 名前空間ランタイムまたはセルフホスト Server 向けの、ファーストパーティのサービスモードの決定的ワークフロー・アクティビティ SDK と運用・コントロールプレーンクライアント。Python 3.10 以降が必要です。
Rust SDK2.0 安定版Cloud 名前空間ランタイムまたはセルフホスト Server 向けの、ファーストパーティのサービスモードの決定的ワークフロー・アクティビティ SDK、Worker サービス、コントロールプレーンクライアント。Rust 1.86 以降が必要です。
Server2.0 安定版v2 コントロールプレーン・Worker プロトコル向けの、PHP で実装された言語中立のセルフホストランタイム。
Waterline2.0 安定版Cloud は Managed Waterline を含みます。セルフホストの運用者は Server 名前空間に対してサービスイメージを別途デプロイします。組み込み Laravel では Composer パッケージをインストールし、アプリ所有の状態をプロセス内で読みます。

PHP、Python、Rust が、三つのファーストパーティのサービスモード SDK 言語です。ランタイム検出が公開済みの機能を報告する場合、それぞれがプロビジョニング済み Durable Workflow Cloud 名前空間ランタイム、またはセルフホスト Server を対象にできます。安定した文字列型名、一つの永続コマンド・履歴モデル、コントロールプレーンバージョン 2、Worker プロトコルメジャー 1、公開ペイロードエンベロープを共有します。Rust はワークフロー SDK であり、生のプロトコル呼び出しだけでなく、決定的なワークフローコード、アクティビティ、Worker サービスを実行します。Python は、ワークフロー記述と、名前空間、スケジュール、Worker、キュー、履歴、修復などの運用クライアント機能を併せ持ちます。

組み込み Laravel は、引き続き独立したアプリケーション内 PHP デプロイモードです。PHP サービスモードのクライアントや Worker に必要なものではありません。フレームワークに依存しない PHP SDK は、組み込み Laravel エンジンと独立したバージョンで提供します。

デプロイモードで所有境界を選び、Cloud マネージドランタイムまたはセルフホスト Serverに進んでください。以下の機能の証拠は、選択したランタイムが必要な契約を通知する場合にだけ適用されます。

PHP SDK 2.3.2、Python SDK 2.5.7、Rust SDK 3.5.0 の既定 Worker プロトコルは 1.20 です。既定 Worker には、メジャー 1 内の 1.20 以降を通知する Server が必要です。各 SDK は、古い互換 Server 向けに明示的な 1.19 選択もサポートします。協調的キャンセルには 1.20 と明示的な機能のオプトインが必要です。互換性はランタイム検出と選択した SDK の公開メタデータで判断します。バージョン互換性と Worker プロトコルを参照してください。

機能と SDK の最低対応版​

「サービスモード」は Cloud またはセルフホスト Server がリモートランタイムを所有することを意味します。「組み込み」は Laravel アプリケーションがプロセス内でランタイムを所有することを意味します。SDK 欄は意図的に差分を記録しています。空欄や制限付きの SDK に同等性があるとは解釈しないでください。

機能現在の 2.0 契約とファーストパーティの最低対応版明示的な 2.0 の証拠
ワークフローリモートの PHP、Python、Rust Worker で決定的なワークフローを記述します。組み込み Laravel の記述には Workflow パッケージを使います。ワークフローの記述、PHP SDK、Python SDK、Rust SDK
アクティビティとサービス組み込みエンジンと三つのサービスモード SDK すべてでアクティビティを記述できます。Rust のワークフローとアクティビティはファーストパーティ Worker サービスで実行します。Python と PHP はファーストパーティの制御・サービスクライアントも提供します。アクティビティ、PHP SDK、アクティビティ実行、外部実行
名前空間をまたぐサービス呼び出し埋め込み PHP、PHP SDK、Python SDK は登録済みサービス操作を永続的に記述し、完了または受け付けだけを待って結果を記録します。PHP サービスモードの対象名前空間は現在、配列の namespace オプションで指定します。Rust の呼び出し記述は sdk-rust #86 が完了するまで利用できません。埋め込みの記述方法、共通カタログと SDK 対応
シグナル現在の最低対応版で、PHP、Python、Rust のワークフローインターフェースから永続的な非同期変更を利用できます。シグナル、Python SDK、Rust SDK
クエリ読み取り専用のリプレイクエリをサポートします。PHP、Python、Rust はクエリハンドラー・クライアントを公開します。Rust のリプレイクエリタスクには Worker プロトコル 1.8 以降が必要です。クエリ、Python SDK、Rust SDK
更新PHP、Python、Rust はクライアントと Worker ハンドラーの更新インターフェースを公開します。Python の宣言済みバリデーターは、Server 検出がその正確な契約を通知する場合、受理前の同期検証を使います。承認後に受理され、拒否、Worker 喪失、タイムアウト、フェンスされた完了は明示的に失敗します。PHP と Rust はバリデーターの記述を公開せず、バリデーターを宣言しません。更新、Python SDK、Rust SDK
タイマーサービスランタイムが支える永続タイマーを PHP、Python、Rust でリプレイします。タイマー、Rust SDK
リトライ永続アクティビティのリトライポリシーをコマンドとともに記録します。PHP、Python、Rust は現在の最低対応版でアクティビティのリトライオプションを公開します。失敗と復旧、Python SDK、Rust SDK
タイムアウトCloud とセルフホスト Server のサービスモードランタイムは、アクティビティとワークフローのタイムアウト各種を強制します。Rust にはアクティビティオプションと、ワークフローの開始時に設定する実行全体・個別実行の期限があります。タイムアウト、Rust SDK
子ワークフローPHP、Python、Rust は永続的な子を開始して待機します。言語間の型識別情報は安定した文字列で、子のペイロードは共通エンベロープを使います。子ワークフロー、Python SDK
決定的な並列合成PHP の all()/parallel()、Python の入れ子の list-yield、Rust の WorkflowContext::parallel()/join() は、アクティビティ、子ワークフロー、タイマー、混合・入れ子グループを通常のコマンドでスケジュールします。三つとも共通のグループ識別・パスメタデータを公開し、入れ子の入力順で結果を復元します。並行処理、Python SDK、Rust SDK
永続的な最初の完了の選択組み込み PHP と PHP、Python、Rust サービス SDK は、独立したアクティビティ、子ワークフロー、タイマー、外部入力待機、入れ子グループのメンバーを開始します。安定したメンバー識別情報とともに一つの勝者を永続化します。勝者以外は続行し、待機・キャンセル用ハンドルを保持します。並行処理、Python SDK、Rust SDK
Saga 補償PHP の Saga ヘルパー、Python の WorkflowContext.saga()、Rust の WorkflowContext::saga() は、前進処理の成功後に永続的な補償を登録し、既定で逆順に逐次巻き戻します。Python と Rust は最初の補償失敗で停止し、起点の失敗と補償失敗を保持します。PHP はオプトインの並列・エラー時続行ポリシーも公開します。Saga、Python SDK、Rust SDK
キャンセル組み込み Laravel とサービスモードの PHP、Python、Rust は、明示的に有効化した Worker で、一つのルート識別情報、不変の期限、上限付きの後処理を伴う協調的キャンセル要求をサポートします。選択実行の安全性と型付き結果を持つ、即時の終端キャンセルも引き続き利用できます。キャンセルと強制終了、サービスモードのキャンセル、Rust SDK
強制終了実行を即時に閉じ、区別された終端結果を記録します。Cloud とセルフホスト Server のサービスランタイム、CLI、PHP、Python、Rust の制御インターフェースから利用できます。キャンセルと強制終了、Server API
副作用PHP、Python、Rust は非決定的な値を一度だけ記録し、リプレイでは記録済みの値をデコードします。副作用、Python SDK、Rust SDK
ワークフローストリームPHP、Python、Rust は、Server 所有の実行単位の出力ストリームに対して、型付きの一覧、詳細、オフセット購読・再開、追記、終了、エラー操作を公開します。三つとも永続コマンド識別情報からリプレイに安全な出力を記述します。Python は設定されたストレージドライバーで外部ペイロードを解決し、PHP と Rust は不透明な参照を保持します。ワークフローストリーム、正確な SDK マトリクス、ランタイムシナリオ
バージョンマーカーPHP、Python、Rust は、互換性のあるコード進化のための永続バージョンマーカーを公開します。バージョン管理、Python SDK、Rust SDK
決定的リプレイPHP、Python、Rust のワークフロー Worker は、外部作業を再実行せず、永続履歴から判断を再構築し、型付きの非決定性を報告します。実行保証、プラットフォーム適合性、Rust SDK
スケジュールCloud とセルフホスト Server のサービスランタイムが永続スケジュールを所有します。PHP、Python、CLI はスケジュール操作を公開します。Rust はスケジュール管理 API を提供すると主張しません。スケジュール、CLI リファレンス、Python SDK
名前空間サービスモードランタイムは名前空間単位です。選択したランタイムが操作を公開する場合、PHP/Python クライアントと CLI は名前空間を管理します。Rust の Worker・クライアントは名前空間を対象にしますが、現在の最低対応版で名前空間管理を提供するとは主張しません。名前空間、認証、Worker、Server API
検索属性Cloud とセルフホスト Server のサービスランタイムは型付き検索属性に索引を付けます。PHP と Python は記述・制御インターフェースを公開し、CLI と運用者 API は構造化された検出・フィルタリングを公開します。検索属性、Python SDK
Worker 互換性SDK はランタイム、SDK バージョン、ビルド ID、対応型、プロトコルバージョン、容量を登録し、Server は受け入れるバージョンとルーティングの事実を公開します。互換性、Worker の互換性とルーティング
ローカルアクティビティ組み込み Laravel、PHP・Python サービス SDK、Rust SDK 3.1.0 で、明示的な Worker オプトインにより利用できます。組み込みアクティビティ実行、サービスモードの対応マトリクス
Worker セッション組み込み Laravel、PHP・Python サービス SDK、Rust SDK 3.2.0 で、明示的な Worker オプトインにより利用できます。Worker セッション、サービスモードの対応マトリクス
スティッキー実行組み込み Laravel と PHP サービス SDK で利用できます。Python と Rust も、明示的な Worker のオプトインにより、任意の上限付き履歴キャッシュを提供します。すべての Worker は正しいコールドリプレイ動作を維持しなければなりません。スティッキー実行、サービスモードの対応マトリクス
コーデックの相互運用性PHP、Python、Rust は公開された codec + blob エンベロープと、一つの固定された再帰 Avro Value スキーマを使います。名前付き分岐が、整数と double、テキストとバイト列、真偽値と整数、リストとマップの区別を保ちます。Avro Value プロトコル、Worker プロトコル、Rust SDK
診断サービスランタイムと CLI は、バージョン、プロトコル、Worker、タスクキュー、リプレイ、履歴、型付きの失敗、修復の事実を JSON で公開します。Managed Waterline、別途デプロイするセルフホストサービス、組み込みパッケージが、それぞれを所有するランタイムの証拠を提示します。監視、CLI リファレンス、Waterline 運用者 API
エージェントツール検出 -> 変更 -> 実行 -> 診断 -> 修復を、公開マニフェスト、スキーマ、HTTP 操作、CLI JSON、SDK クライアント、型付き履歴・診断、安全な変更から利用できます。MCP は任意の一インターフェースであり、この機能の定義そのものではありません。エージェントツール契約、エージェント運用ループ

ペイロード相互運用性の境界​

言語をまたぐワークフロー・アクティビティ呼び出しは、シリアライズされた PHP オブジェクト、Python pickle、Rust 実装型を渡しません。登録された文字列型名と公開ペイロードエンベロープを渡します。avro では、各ファーストパーティ SDK が公式の言語実装と同じ固定 Value スキーマを使います。デコードされたマップ、リスト、文字列、バイト列、整数、double、真偽値、null は、プリミティブ型を保ちます。言語固有のクラスを再構築するのは、その SDK 内だけです。

この契約は、ワークフローの入力と結果、子ワークフロー、アクティビティの入力と結果、シグナル、クエリ、更新、外部実行に適用します。デプロイ時には、Worker を受け入れる前に GET /api/cluster/info が通知するコーデックを検証する必要があります。
