# スポンサー {#sponsors}

Durable Workflow は、スポンサーとボランティアを通じてコミュニティに支えられています。このパッケージが役立った場合は、継続的な開発への支援をご検討ください。

## 現在のスポンサー {#current-sponsors}

- <a href="https://freispace.com" target="_blank" rel="noopener sponsored">Freispace Resource Scheduling</a>
- <a href="https://translateabook.com" target="_blank" rel="noopener sponsored">Translate a Book</a>

## スポンサーになるには {#becoming-a-sponsor}

継続的な開発を支援するには、[GitHub Sponsors](https://github.com/sponsors/durable-workflow) をご利用ください。
